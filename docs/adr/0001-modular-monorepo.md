# Start JuanerAI as a modular monorepo

JuanerAI will begin as one modular monorepo because Xanthil and the reusable capability modules need to evolve through shared contracts and atomic vertical Changes. Module boundaries remain explicit and independently versionable; extraction into separate repositories is deferred until ownership, release cadence, security, scaling, or reuse creates a real boundary that outweighs cross-repository coordination cost.
