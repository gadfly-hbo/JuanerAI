# 通用插件验收清单（按适用性选择）

用于[标准](standard.md)五步流程的“验证”，结合[参考Adapter](report-studio-reference-adapter.md)寻找实际接点。它不是全插件强制Gate，也不是本次任务的运行授权。

每个选中项放入现有OpenSpec／验证记录：本插件适用理由、正负例与预期、候选源／物料／环境／输入／权限身份、命令／退出／可读证据、实际结果及限制／返回点。已有等价记录直接引用，不新增审批台账或统一结果Schema。

## 结果口径

- **N/A**：实际没有该能力，说明原因，例如纯库无自有服务进程；不是权限、环境或材料缺失。
- **未授权／未执行**：能力可能适用但当前无真实权限或未运行；不写成N/A／PASS。
- **旧有效证据复用**：列原候选、接点、输入／环境／授权及仍有效的原因；变化和相关风险补验，不机械重跑全部旧项。
- **新检查PASS／FAIL**：有当前候选实际命令、可读输出及退出；环境／夹具失败与产品反例区分，失败原件保留。
- **用户接受但未实测**：记录用户明确决定和接受范围，技术事实保持NOT_MEASURED／UNKNOWN，不代行Validator PASS。

以上是检查记录用语，不增加产品状态枚举。UNKNOWN效果／消费、取消未物理停和旧失败不因新候选或新Task ID被清除。

## 按真实能力选择的正负例

|---|---|---|---|
| C01 固定身份／兼容：所有固定采用 | 固定源、物料、依赖及兼容组合与实际消费者一致 | 未知版本、摘要不符、缺失／坏包、链接逃逸在使用前拒绝，不回退活动源码或latest | 版本＋bytes／SHA／来源／包内清单；校验器正负例和实际目标身份。hash不等于签名／接受 |
| C02 双交付／资源：按获准形态 | 独立入口消费同一业务实现；集成版从JuanerAI随包资源启动／调用，含必要依赖及通知，无需用户另装插件／源码仓库／全局环境 | 资源缺失或被换、存在开发机绝对路径依赖时不伪装就绪／不自动寻找独立版 | 当前获批独立／集成物料对应表、实际包内消费者／资源与安装证据；未制作或未授权形态保留未执行 |

| C06 效果／重试：有副作用时 | 按合同幂等或明确重复拒绝，丢回复后查询原receipt／同字节产物 | 效果UNKNOWN不盲重放；无法读回、错对象或哈希不符不宣称成功 | 真实事务／效果接点合成故障及独立读回，明确发布点与丢回执。模型结束、工具返回或单独hash不证明业务效果 |
| C07 状态／取消／迟到：有异步效果时 | 受理、工具、业务与持久保存成功分别呈现；取消后按合同关闭新准入 | 保存失败、未知效果、错误、迟到成功不得冒称正式完成／自动恢复；保留原错误类别 | 失败后持久状态、真实取消／迟到接缝；有UI核对实际可读反馈，不能由任意异常文案猜精确原因 |
| C08 产物与来源：有正式产物时 | 结果可读、版本／来源／限制保持；明确保存后可稳定取得 | 缺文件、坏字节、错来源／历史版本不成功，不退回最新版；工作副本丢失不抹已有正式副本 | 可访问文件＋长度／hash／来源与实际消费者读回；产物格式和质量由业务定义 |

| C10 LLM／执行：启用这些能力才适用 | 用实际固定SDK编解码走合成请求／工具／已启用辅助或备用，共用任务授权与计量；单次窗口／输出／超时有效 | 漏计、越权、未知消费自动退款、隐藏重试、超限成功、未授权恢复均拒绝 | 精确SDK／依赖／配置身份＋合成实际codec／账本／工具接点；回放不证明被模拟的Provider或OS严格隔离，真实调用单独授权 |
| C11 业务正确性／可见行为：每插件分别选择 | 同一代表业务任务结果可核查；用户理解入口、范围、结果和必要风险 | 无效转换、错来源、误导成功、错误指标或权限混淆不得接受 | 清洗验变换／行与字段，采集验来源／允许范围，报告验呈现／可编辑及来源；新可见行为按原UI合同，不给全部插件套PPTX／Keynote／三格式 |

## 本次沉淀任务怎样应用

本次没有新插件、运行包、独立发行、产品UI、Schema或真实效果；不启动以上全部未来验收。实际执行的是三资产内容／引用／范围检查、已发布固定物料只读核对及真实Application／Store／准入等已有合成正负例；原接受按身份复用。无新行为，不编造业务RED；不安装依赖、不操作真实用户应用／服务／凭据／数据或Provider。

本次未证明新独立发行包、融合.app安装／运行、干净机、其他OS／架构、新载体／第二插件、两修复已回流及未来目标包含性。原用户接受风险和全部FAIL／UNKNOWN／未知预留保持。最终本地候选、实际命令／结果、独立复核及未完成项统一见[验证记录](../../../openspec/changes/plugin-integration-consolidation/verification.md)，不得以清单存在将未执行项自动标通过。
