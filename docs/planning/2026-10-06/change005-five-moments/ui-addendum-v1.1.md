## 3. 演示的可点击路径

1. 默认“口径冲突”：查看来源／修改候选→“本次使用净销售額”→可读计划；明确本次不是项目定义发布。
2. “调整分析重点”→影响预览：移除渠道，聚焦高价值会员／退款→接受修改；看真实消费者要求，而非新增审批向导。
3. 审核场景“执行异常”：查看步骤、检查关联规则、取消退款分支；只保留订单金额事实，不把依赖退款的净销售额冒充核验成功。停止／重开／UNKNOWN分别有不同状态。
4. “逐条发现”→查看某条证据／提出异议；看核验与替代解释不同。重大限制在主卡及报告摘要都可见。
5. “影响预览”→仅看高价值会员→模拟完成核验→旧／新对照→采用或保留；横幅明确这是合成切换，不是实际计算。
6. “下次复用”→查看可沿用项→显式采用→新任务重新检查当前资料；旧数字与核验不复制，合成来源只供审核，不访问真实项目。

专业模式新增检查应接同一任务的对应口径／计划／证据／报告／历史位置，沿用完整六阶段，不重建界面或采用006占位。本静态iframe仅提供既有专业视觉参考；**同一后台事实和新行为在专业中的接线仍须工程实际验证，样例不证明它已完成**。

## 4. 失败、访问性、状态与评审边界

复用Q11缺资料、前提错误、停止、重开、UNKNOWN、授权失效／秘密遮蔽／下载回执。有效授权后台复用，明细许可、主备共享一次额外请求及持久计量不变；出站详情描述实际允许及实际发送范围，不再承诺零明细。

主区保留对话、顶部目标／口径／状态；抽屉按需展开，重要限制不藏高级。宽屏1440×900及1366×768，窄屏390px健壮性；Tab／可见焦点、Escape返回、表单标签、文本＋状态色及长内容换行。窄屏抽屉覆盖而非三列压缩；不新增移动端生产承诺。
