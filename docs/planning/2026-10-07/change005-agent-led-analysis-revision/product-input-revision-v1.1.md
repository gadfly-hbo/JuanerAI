## 3. 对焦：标准化含义和边界，不限制用户说法

### 3.1 单一共同理解

业务语义和数据/指标能力向同一Agent提供当前有权限、版本明确的依据；Agent结合用户自然语言提出或补齐目的、对象、指标含义/单位、期间/粒度、可用资料、关系、限制和交付目标。无需先由程序猜一套完整需求，再交Agent从头理解第二套。

“标准化分析需求”是后台形成的可执行业务约定，包含目标/交付、Context来源/版本、必要Binding、固定计算条件、允许的方法/工具及剩余未知；不要求用户填写标准句式、JSON或字段表。只有实际执行需要的语义项才必须齐备；普通对话、文档整理和表达修订不强造量化IR。

自然表述（如“万，人民币”“只看老店”“先等等”）由LLM结合真实对话与资料理解，不能通过新增短语词典逐例修补。后台核验来源、作用域、权限和可执行一致性；模型的规范值不需逐字出现在引文中，解释不冒称人工确认。不能从模型解释/列名相似直接确立长期业务事实。

### 3.2 既有指标与知识复用

使用有真实来源、有效版本和适用范围的已有项目指标树/定义、绑定或选定业务说明；无需每题重复列出及确认。知识/记忆是依据或背景，非天然业务真源。缺少项目指标库时不得编造其存在，可直接使用用户已选业务定义文件，在任务中形成有来源快照；本次不前置新建完整知识库/本体管理平台。

用户当前明确修改可作为任务级新定义；它与项目标准有差异时记录并简短说明，不自动覆盖长期标准。来源冲突、过期、失权、结构不适用，或不同解释会实质改变结论且无可靠选择依据时，只询问依赖的具体问题。当前显式要求本身清楚时不再让用户确认同一件事。缺定义但含义可可靠明确时自动推进，并可查解释来源；非必要背景未知可带限制继续，不给影响结论的字段默设业务默认。

例如项目已有净销售额=订单额−合法关联退款的定义、来源单位及字段对应均适用时，用户提问即可直接计算；不存在该定义时不能伪称“已沿用项目口径”。订单明确万元、退款明确元时自动按真实倍率换算并核验，不把可换算单位差异当作冲突；同一字段的有效来源互相矛盾或必要单位无法确定，才就地问一个必要问题。真实关联基数冲突同样处理，其他不依赖部分可继续。

## 4. 对焦后自主分析：Context稳定、执行计划可演进

初始Context/Binding和方案构成当前任务版本的可信分析依据；IR是实际执行/验证契约，不是完整思考脚本，也不是只用来生成界面的JSON。每次执行必须对应当前有效输入/口径及真实计划、代码/方法身份。

简单计算可一次生成完整IR并直接执行、核验、回答。经营分析等多步骤任务先确定目标、指标体系、资料/期间、比较依据及交付要求；Agent可根据真实工具结果选择下一分析动作，生成/调整Python、探索异常、改变方法或图表，不需要用户逐节点批准。

在固定目标/口径/资料授权范围内，增加检查、替换分析方法、修正程序、整理报告由Agent推进并留记录，不重复建立整套需求或人工审批。动态动作仍须落到实际受控IR/代码消费者；不得用任意代码旁路IR/权限。业务含义/目标/范围/输入改变则走FM-X新版本、影响及受影响重算；表达改变不重算事实。新权限、正式人的效果或不可安全继续才暂停相应动作。

Agent可提出预测/因果问题、检查资格；缺识别条件不按名称拒绝全部任务，也不能将相关/前后比较写为因果。方法能力无法达到时保留有用描述和准确缺口，不能改目标后声称原任务完成。

### 4.1 生成分析代码与独立核验

可编写Python完成获准数据检查、转换、组合指标、分组/期间比较和图表，复用现有已安装能力。输入限已选授权快照，原件只读，输出限任务派生区；禁止生成代码联网、Shell/子进程、安装、凭据或任意目录访问。执行隔离/资源限制不能保证时拒绝该动作并明确缺口，不靠提示词承诺安全。具体工具协议、Schema、资源值由工程在原授权内确定；不得默增主机/依赖权限。

代码退出0只说明执行成功。关键数值/业务事实使用适用独立路径：原数据对账、独立重算、守恒/统计不变量或方法验算；同代码再跑、模型自评不是独立证明。仅有局部核验时明确覆盖和限制；未经核验探索可查看，不升为已核验事实。预测需适用样本外评价/不确定性，因果需识别前提；本稿不认证所有专业方法。

原同一失败代码操作最多一次受检纠正，模型操作至多一次额外请求且主备共享，不改操作身份绕限。成功探索后的新业务步骤不是同一失败重试；账本持久保留。材料许可内的派生图表/报告无需逐次落盘人工批准。

### 4.2 一致性目标

同一数据版本、口径、实际方法/参数及执行条件，应能追溯并复现已声明的计算；方法有随机性时记录影响结果的种子/参数及适用误差条件，不能承诺所有随机输出逐字/逐值一致。模型叙述、分析角度可不同，不能无解释改变事实/口径。方法选择引起不同结果须说明方法与限制；正式比较不能混用不同范围/分母。不是固定整篇报告措辞或预制报告模板。
