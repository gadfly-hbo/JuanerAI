审核入口：[打开可点击 UI](clickable/index.html)；业务语义、支持范围及验收以[产品输入](product-input-v1.3.md)为准。[v1.1 UI](../../2026-10-05/change005-ui-contract-recovery/ui-contract-v1.1.md)、[五时刻 UI](../../2026-10-06/change005-five-moments/ui-addendum-v1.1.md)、[v1.2 UI](../../2026-10-08/change005-v1.2-requirement-sandbox/ui-contract-v1.2.md)的未变部分及用户批准继续有效，不重做整套视觉。

## 1. 不变的工作台与增量所在

PX-006：左项目／会话、中央自然对话与展开成果、右按需抽屉；PX-004：完整专业六阶段，不采用 PX-006 的专业只读占位。白／浅灰、绿色主动作、中文优先，JuanerAI 字标与“持续做出更好的决策”、无图片 Logo；“新建分析”仍紧凑，最大高度40px，不恢复大方框。保留 Skill／Prompt、文件资料、历史、手动 Fork／Subagent、报告、人审和模式切换的既有能力，不另造 Agent 管理平台或专业表单工作台。

六阶段继续中文显示：新建分析、数据准备、本地处理、证据分析、报告、执行反馈。五时刻和需求沙盘是同一工作台的检查／接管面，非固定页数、逐卡审批、强制路径或内部循环调度器。普通用户不用理解 Context、Binding、IR、Attempt 等对象；必要摘要使用业务语言，技术身份在检查详情里可查。

本审核件直接引用既有 PX-006 CSS、brand.css、workspace.css、五时刻 moments.css，仅加本次状态与协作面。顶部审核场景和“推进合成事件”是评审控件，生产不得照搬或将其假状态交付。横幅始终标“合成审核，不是实现证据”，无 Provider／真实文件／真实计算／持久保存，刷新清空；任意文本只安全显示，不伪装已经理解和执行。

## 2. 可见要求与产品映射

| UI ID／产品要求 | 展示、动作及边界 |
| --- | --- |
| AUUI-01 / AU-01、FM-03 | 中央显示用户目标、当前任务／版本、实际调查工作和等待原因，可展开近期调查记录；自主路线可能跳过、回查或分解。生产来自真实事件，不固定“第几步”、虚假百分比／倒计时。不显示隐藏思维链 |
| AUUI-02 / AU-02、RS-01～08 | “需求与框架”“答案预演”保留；从复杂调查按需返回沙盘，简单任务无需深入问答。整体框架可审阅／修改，保存暂不分析、明确开始及已保存状态区分；答案预演标“非事实、未分析”，只整理不产生计算成果 |
| AUUI-03 / AU-03/04、FM-01/02 | 原五标签抽屉仍为口径／方案／资料／证据／执行。口径显示来源／业务含义／冲突；方案区分可读调查路线与实际计算方法／参数、Binding、IR／代码身份及核验。不是常驻 JSON 编辑器或三个技术控制台 |
| AUUI-04 / AU-06 | 左会话能定位父／子／孙关系和独立历史；协作展开面列发起者、目的、精确资料子集、真实状态、返回与使用位置。用户可主动 Fork／Subagent；自主发起不弹每次批准。容量排队、等待权限及停止分别表达，不假称已经执行 |
| AUUI-05 / AU-07、FM-04 | 自动回流摘要区分“已返回”“用于后续调查”“已核验”“待人判断”；可追到主 Agent 后续如何使用、冲突补查及保留缺口。不强制逐返回先点采纳，不用多个 Agent 的共识图标冒充独立核验 |
| AUUI-06 / AU-08/09、FM-X | 普通补查／方法参数调整显示可查记录即可，无新审批；改已确认目标／口径／交付承诺在展开面展示具体差异、受影响及保留部分、采纳／保留原目标。采纳不单独解除 UNKNOWN／权限缺口；新版本未算不显示新成果 |
| AUUI-07 / AU-10、FM-03 | 根停止位置清楚；分支可停自身及后代。受理停止、在途结算、已停止、UNKNOWN 分开；根停止不只改主状态。显式对账／恢复按钮按事实出现，不因刷新、历史浏览、切模式或新建同名分支绕过停止 |
| AUUI-08 / AU-05、FM-04、OA-08 | 原成果展开面可切表、图、报告。每条主要发现带适用核验、限制、未查反例和对应证据；整体报告不统一标绿。认可／异议绑定精确成果版本，会员正式整体人审保留，不用自动回流生成 Decision／Expected |
| AUUI-09 / AU-10、OA-RT | 执行详情可查根及后代的真实累计／失败／未知预留、模型与实际配置身份；明确累计暂不封顶不等于免费／无保护。一次额外请求共享主备与重试。凭据、未授权明细、私有路径、内部思维链不展示。SDK 升级由用户另转交，不做升级按钮或前台迁移流程 |
| AUUI-10 / FM-05、RS-08 | 原显式沿用历史方案入口和双模式同一任务／版本保留；不沿用旧数字、核验、决定或授权。生产专业视图与快速窗口消费相同持久事实和状态；本增量不能靠独立 iframe 假称已接通 |

原专业六阶段的完整交互源在审核件中可进入 PX-004 iframe 参考，**该参考与当前合成任务不共享状态，不是生产同版本证明**。本增量主要评审新增快速可见行为；未变专业页面、完整正式决定表单、文件权限界面、下载／保存与历史方案采用继续由上述有效合同覆盖。生产必须把增量调查、沙盘、协作和停止状态接入同一专业任务，不得交付占位专业页。

## 3. 可点击审核路径

| 审核场景／路径 | 可检查终点及不能出现的误导 |
| --- | --- |
| 开放任务／简单明确 | 推进合成事件→主 Agent 自主双子任务及孙任务→自动回流消费／补查→成果展开→逐条证据／人判断。简单目标直接推进，不以完整沙盘问卷为前置 |
| 只整理需求 | 需求与框架→答案预演→保存暂不分析→读回，仍无计算成果；明确开始才进入调查。保存、整体审阅不冒充执行授权或正式判断 |
| 业务歧义 | 说明关键“订单额／净额”差别→用户选择本任务口径→框架更新／未分析→明确开始；不能 AI 静默认定企业定义 |
| 新资料权限缺口 | 展示 D2 未获外发许可→暂不授权、保存待补；不拿根旧许可覆盖新资料。不在原型内提交真实权限 |
| 自主协作返回冲突 | 查父子历史／资料子集→返回冲突→主 Agent 补查→净额待补证、订单额部分成果；未经核验解释不成为原因结论 |
| 修改目标／口径 | 看差异→保留原目标无变化，或采纳差异→新版本／受影响封闭→明确适用推进；旧版历史留存，未重算不显示新数 |
| 方法失败 | 同一失败操作一次受检纠正后仍失败→显示部分成果及阻断；不改名无限重试、不将失败显示成功 |
| 停止根／停止子 | 根停止传播后代，结算／UNKNOWN→对账→显式恢复；停子只继续明确不依赖的合法工作，相关报告待补证。被停子不自动换名字重建 |
| UNKNOWN／服务重启 | 迟到返回隔离，UNKNOWN 不盲重发；服务重启暂停，用户显式恢复先核验当前权限／身份及已完成部分，账本不清零 |
| 用户主动 Fork／Subagent | 运行中主动创建合法分支、看独立历史及后续回流；停止／待对账／只整理时入口可解释阻断或建议，但不能真实派发计算 |

点击或重复按钮、跨场景复位都只是可重现的合成审核；不能作为 AS／AC 的生产通过证据。原 RS 保存失败、FM 历史方案采用、正式决定／Expected 和下载失败的未变要求不因本审核件聚焦增量而被删除。

## 4. 状态、访问性与测试适用性

主路径1440×900及1366×768；窄屏390px只验证布局健壮性，不新增移动端产品范围。宽屏保留稳定左会话、中央任务、按需右抽屉；窄屏抽屉覆盖而非挤三列，长中文／文件名／任务目的换行。主动作与次动作层级、间距和紧凑信息密度沿用已接受样式；状态用文字＋颜色而非只有颜色。

按钮／输入／dialog 有标签；Tab 焦点可见，抽屉 tab 方向键、Home／End可用；Escape 返回展开面／关闭抽屉或 dialog，返回动作恢复合理焦点；状态 aria-live 不因每次渲染伪报新执行。异议、保存或操作失败保持内容，不以消失对话冒充成功。

检查记录见[verification](verification.md)：本地语法／引用／合成状态模型与浏览器实际点击／截图／响应式分开。浏览器安全策略拒绝 file:// 时不另起服务或绕过，浏览器项保持 NOT_RUN；可由用户直接打开离线 HTML 审核。静态检查不代替用户 UI Gate，也不证明视觉或生产实现已通过。

Mini 后续必须严格沿用本次用户接受的工作台及这些行为，不另造 UI；若工程证据说明承诺无法满足，先交用户集中取舍，不以自造界面填缺能力。无能力如实说明；本轮 UI 接受不额外开放 Provider、资料、工具、安装、现实行动或 Git 权限。
