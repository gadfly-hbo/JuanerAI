# JuanerAI 前端 UI 首期提案与 Demo v0.1

本交付只围绕六项前端 UI 改造，不修改现有代码仓库、底层流程或工程门禁。

## 先看什么

1. 阅读 `JuanerAI_前端UI首期改造方案_v0.1.md`，确认范围与操作边界。
2. 在本地浏览器中打开 `JuanerAI_UI_Demo_v0.1.html`。HTML 内嵌所有样式与脚本，无需安装依赖或启动后端。
3. 从首页销售下滑案例开始，体验口径确认 → 发现卡片 → 依据面板 → 成果 → 数据选区 → 报告局部编审。

右上角可切换简单／专业模式，点击演示说明可重置本页状态。

## 重要边界

所有业务数字、核验回执和资产绑定都为固定合成示例。上传只记录文件名与大小，不读取或分析内容；新消息的回复为预置交互，不调用 LLM。报告改写只改经营解读段，不改变锁定事实。

原型尝试将任务与草稿保存在标签页 sessionStorage；受浏览器策略限制时退回内存。不要将本页当作可靠资料存储。文件打开和存储恢复仍需在实际目标浏览器验收，详见 `验收记录.md`。
