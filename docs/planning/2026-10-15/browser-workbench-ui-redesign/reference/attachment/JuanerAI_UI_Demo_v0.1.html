把六项 UI 思路走一遍

这是 JuanerAI 首期前端交互提案，不是正式产品。页面无外部依赖，双击 HTML 即可使用。

1从对话启动示例，确认分析口径。2查看发现卡片，按需打开依据面板。3切到成果工作区，勾选数据行并引用到对话。4进入报告编审，选中解读文字，应用或放弃预置改写。5切换简单／专业模式，观察信息深度变化。

演示边界：无 LLM、数据库、真实核验或业务执行；上传只读取文件名与大小，不读取文件内容。示例回执不证明实际调用了任何 JuanerAI 能力。

演示任务、草稿与报告修改尝试保存在本标签页的 sessionStorage；文件元信息仅留在内存。浏览器限制存储时自动使用内存，刷新不保证恢复。初始字母标是 Demo 占位，不替代正式 Logo。
