# 本候选 UI 视觉系统

仅适用 BUI-20261015 浏览器审核包，不新建或替代全项目 DESIGN.md。优先顺序：用户方向／项目批准合同→本候选受影响改版→共享UI基线的补充。用户未批准的新视觉均为提案。

视觉锚点：用户附件六张截图。保持暖白工作台、浅灰绿侧栏、单顶栏、细边界、低噪声；主要信息通过对齐、字重和留白分层，不用深色卡片、渐变、装饰图或重复卡套卡。

| Token | 候选值／规则 |
|---|---|
| canvas / surface / sidebar | #f6f7f4 / #fcfcfa / #f0f2ed |
| ink / text / muted | #22332d / #36443f / #59665e（比附件辅助色加深） |
| green / soft | #27664f / #eaf2eb |
| border / warning | #dce2d9 / #80541c + #fbf3e4 |
| font | -apple-system, BlinkMacSystemFont, PingFang SC, Microsoft YaHei, sans-serif；不下载字体 |
| sizes | 标题24–28，区块16–18，正文14，辅助12，行高1.6；数据用等宽数字 |
| spacing / corners | 4px节律，常用8/12/16/24/32；控件8px，主要面板12px，少量胶囊用于状态 |
| shell | 230px侧栏；单顶栏64px；检查器约340px；成果助手320px；高度不固定整页溢出 |
| controls | 主操作绿色；次操作白底细线；新建分析≤40px；触控建议最少36×36，关键图标提供可读名称 |

组件：稳定侧栏、面包屑与模式开关、任务状态条、可滚动六阶段导航、三视图导航、消息／发现、证据目录、数据表／行引用、引用卡、单稿报告／段落编辑器、差异建议、确认／失效条、检查器／窄屏抽屉、对话框／错误与空状态。每个组件必须有默认、悬停、焦点、禁用原因和必要异常，不靠图标／颜色猜含义。

保留 JuanerAI 字标与“持续做出更好的决策”；不引入附件占位J图标或自造新Logo。正文中文优先，技术ID只放可展开来源。现有专业事实／证据语义优先于视觉简化。

最终实现需真实浏览器验证对比度、键盘、焦点、缩放与断点；原型静态样式和合成检查不证明这些全部通过。
