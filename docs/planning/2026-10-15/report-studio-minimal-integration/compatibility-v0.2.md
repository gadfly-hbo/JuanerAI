## 建议批准的最小范围

1. **安装与运行只承诺上表两组 Apple Silicon + macOS 组合。**这不是“macOS 26.3.1 及以上”、全 M 系列或 Intel 支持声明。系统更新或另一芯片需补受影响检查后再扩展承诺，不预设一定不兼容。
2. **PPTX 主编辑验收为两台机器上的 Keynote 14.4。**无需先买或安装 PowerPoint。PPTX 仍是交付格式；Keynote 只是首版打开、编辑及保存回读的验收工具，不改为仅输出 .key。
3. **网页工作台与 HTML 验收为上表各机 Chrome 155 的已安装版本；PDF 阅读使用各机 Preview 11.0。**Safari 仅记录现状，暂不增加一套浏览器承诺；不据此移除 JuanerAI 已有其他浏览器支持。内置 Chromium 是后台 PDF 渲染依赖，不要求用户自行安装它。
4. **保持 PPTX／HTML／PDF 三格式，保留近似预览说明。**不降低 v0.1 AC12 的编辑性要求。Keynote 导入后若原生表格／图表被打平、文本不可编辑或有严重裁切，就是失败；不能因独立版可用而豁免。若工程发现该承诺无法满足，先返回明确差异供用户取舍。

## 如何判定首版真正可用

| 验收 | 本补充确定的检查对象与终点 |
| --- | --- |
| AC01 干净安装 | 固定同一 JuanerAI 包及插件版本，在两组目标环境分别验证。使用隔离的干净用户环境或等价干净验收环境，不依赖现有仓库、Node/npm、浏览器缓存、独立版配置或认证。只改 PATH 或在原开发账户启动不能单独证明干净安装。环境建立、安装、调用和打包仍须之后实际授权。 |
| AC02／AC03／AC04／AC10 | 两机都覆盖关联项目与独立项目、显式配置、获准合成材料、生成改页导出和权限反例。MacBook 上独立版与内置版须共存且不接管其数据／服务。Mini 应证明没有独立源码依赖。 |
| AC12 PPTX | 在两机 Keynote 14.4 中打开获准合成样张，修改中文标题、正文、表格单元格、原生图表数据并保存为 PPTX，关闭后回读验证修改和版面；导入图片仍可为图片。检查字体替代、长中文、换行、分页、裁切与重叠。不能用静态 OOXML 检查替代实际编辑器验收。 |
| AC12 HTML／PDF | 在对应 Chrome／Preview 打开三格式同源样张，主要内容可阅读、无严重缺页或裁切；明确与 PPTX 的近似差异。普通视觉差异记录后交用户接受，严重阅读／编辑失败阻断交付。 |
| AC14 UI | 用户在固定安装候选完成主路径，辨认来源、制作状态、停止范围、交付回执和返回位置。本轮离线原型只审核 UI，不能代替该实际验收。 |

无需建立“两种 OS × 两种芯片 × 所有编辑器”的笛卡尔积。首版就是两台现有目标机；使用同一可识别交付候选验两组组合。跨机器自动同步项目或报告仍不在范围内。
