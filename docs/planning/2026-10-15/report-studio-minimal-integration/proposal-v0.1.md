# Report Studio 最小接入方案审核稿

日期：2026-10-15。版本：v0.1。状态：待用户审核，未冻结产品输入，暂不开发。

本方案采用用户已确定的方向：**Report Studio 作为关联模块独立维护，固定版本随 JuanerAI 一起交付，后台按需启动，保留自由制作能力。**用户在一台没有 Report Studio 独立仓库、没有预装 Node/npm 的受支持 Mac 上安装 JuanerAI 后，即可打开该模块；需要模型的制作步骤在完成有效配置和授权后使用。

本轮只交付方案文档。方案审核不等于安装包已经具备此能力，也不授权实现、依赖安装、真实模型或数据调用、打包、发布和其他设备部署。本文的具体交互与边界是供本次整包审核的方案，不把助手先前建议当成已单独批准的细节。兼容范围尚待决定，见第十节。

## 一 产品目标与首版范围

面向已有分析结果需要制作汇报材料的个人用户，完成一条连贯任务：

> 选定 JuanerAI 分析成果 → 带入 Report Studio → 对话制作和修改 PPT → 导出 → 关联回原分析 → 重开和下载。

用户也可以在内置 Report Studio 中新建独立报告项目、上传自己的材料并制作；此类项目默认无分析关联。本次不增加任意跨 Case 挂接、一个报告关联多个 Case 或改变关联目标的管理流程。

首版包括 PPTX、HTML、PDF 三种现有导出格式。PPTX 是主要可编辑交付物；HTML/PDF 保留现有渲染方式和近似预览提示，不承诺三格式视觉完全一致。DOCX 输出、通用成果包导入和完整 Case 迁移不在范围内。

产品位置是 Xanthil 的“产品能力与插件 → 数据呈现／Report Studio”。模块名称面向用户显示中文用途；技术身份统一使用实际项目名 `reports-factory`，纠正当前占位字符串 `reports-factroy`，不据此建立通用插件注册系统。

### 与既有产品路线的关系

本方案对应 Blueprint v4.2 的 **C5-09 报告表达与 Report Studio、N11 可复用交付**；关联能力涉及 C3-01 工作台、A-04 运行管理、A-05 来源版本、B-01 证据与不确定性及 B-02 授权。它扩展表达和交付，不取得分析计算、事实核验、正式 Decision 或现实行动的权威。

用户本次确定了随 JuanerAI 交付的目标。本方案在原浏览器加同机服务方向上补充安装与附带模块的消费要求，不恢复已撤回的 Desktop 全量计划，不改变在研 Change、全局优先级或能力清单完成状态。安装载体及具体打包机制由工程提出，必须满足本方案的非技术用户安装和运行验收；不得仅以开发脚本启动代替安装交付。

## 二 用户路径

### 从分析成果开始

1. 用户打开插件入口，选择“使用当前分析成果”。没有可保存的分析成果时，该动作说明原因；仍可新建独立报告项目。
2. 系统展示将带入的成果版本与材料范围。默认范围为该版本的结论、选定表格、来源说明、核验等级和限制；不自动复制整个项目、全部原始数据、会话历史或凭据。来源说明只携带获准摘要或引用，不能借此夹带未授权原文。用户可调整材料选择。
3. 已有有效授权覆盖此次材料和外发用途时直接继续；不覆盖时集中说明差异并请求必要授权。没有模型外发许可的材料可保留为本地项目材料，但不得进入模型上下文、图片理解、页面截图或其他外发路径。
4. 系统创建关联报告项目并带入材料副本，在独立浏览器标签页打开对应项目。再次打开同一分析版本的既有关联时复用该报告项目，不重复创建或再次生成。
5. 用户在插件中沿用框架提案、确认、生成、逐页修改、页面锁定和导出流程。普通编辑和已授权工具调用不增加 JuanerAI 逐步审批。
6. 用户选择一份已经保存的导出产物，点击“关联回原分析”。宿主保存稳定副本和关联记录，成功后提供原分析入口；不要求逐页确认或额外报告审批。首次接入保留这一明确交付动作，不把每次自动保存都回传为新报告。
7. 原分析展示“关联报告”，可查看制作时间、绑定的分析版本、格式、质检提示，打开或下载已保存产物，并进入插件继续制作。

### 修改与新版本

- 在插件继续修改，不改变已关联的报告副本。再次导出并关联时产生新交付版本；旧版本仍可读、可下载。
- 重复关联同一来源与同一导出产物应返回已有记录；若首次回执丢失，先读回结果，不重复创建。
- 原分析生成新版本时，现有报告继续引用旧版本，并提示来源已有更新；不自动重做或替换。用户选择带入新版时，为该新版建立新的关联报告项目，保留旧项目与原交付。跨版本自动复用旧页面、自动合并修改暂缓。
- 插件可新增或改写数字、解释与建议。关联报告须清楚说明其内容可经插件编辑，原分析的核验结论不会自动覆盖这些新增内容；不要求首版实现逐句自动差异审计。
- 进入插件独立制作的项目保持独立。首次接入不提供其事后挂到任意分析的入口，避免额外目标选择和来源迁移规则。

| 代码与 Bash 执行 | 采用用户选择的可信本地工具方向，保留在有效任务权限内执行生成代码、联网取材及必要工具操作的能力；不以项目工作目录冒充系统级隔离。 |

### 自由制作的权限含义

可信本地模式下，生成代码和 Bash 可能具有当前用户的系统访问能力；独立进程、工作目录和提示词都不是严格沙箱。首次启用需清楚展示该模式及当前材料/外发授权，用户接受后在有效范围内运行；不逐命令确认。本方案不把已有独立工具的历史授权自动继承到内置版，也不承诺企业级强隔离。

内置版不自动读取 `.pi`、`.zcode` 或独立 Report Studio 的认证与会话。用户通过产品配置提供模型凭据；凭据不进入发布包、材料副本、报告或前端回传。生成代码进程只获得其执行必要的环境，不默认继承模型密钥；这项必要的凭据处理不取消自由制作能力。

任务授权可以覆盖一组明确用途。新增图片、报告截图、外部资料或下载后内容是否可发给模型，取决于同一有效边界。图片上传或页面预览不能成为未声明的自动外发；撤销授权后关闭新的受影响调用，在途请求按事实结算，不承诺撤回已发送内容。

## 五 随包交付与后台启动

### 干净 Mac 的安装体验

用户安装 JuanerAI 后，插件入口和基础制作环境随包可用。安装位置可以变化，不依赖开发者主目录、仓库、系统 Node/npm、预先安装的 Chromium 或独立版服务。基础启动、材料浏览和已有产物查看不要求运行时下载安装依赖；模型生成及用户获准的联网取材仍需要网络。

没有模型配置时可打开模块、管理项目及查看已有产物；需要模型的动作明确提示配置缺失，不悄悄发现其他应用密钥。具体配置界面沿用适用产品机制；新增行为纳入后续 UI Contract。

安装包制作方式、具体目录和端口属于工程设计。必须列明可再分发依赖及许可证、支持硬件与系统范围，验证安装及首次启动实际可用。不得把依赖清单、开发机运行或发布包存在替代干净机验收。

### 生命周期

| 场景 | 对用户的行为 |
| --- | --- |
| 首次打开 | 自动启动内置实例，显示真实启动状态；就绪后打开项目。启动失败不创建虚假的可用状态，用户可重试。 |
| 重复打开或多标签页 | 复用同一内置服务和目标项目，不重复生成；同项目的运行占用与插话语义沿用插件，不因此新增并行任务能力。 |
| 端口被占用 | 不结束未知进程、不连接来源不明的同端口服务；选择安全可用的端点或清楚报错。 |
| 关闭制作标签页或返回分析 | 不等于停止；后台制作可继续，重开能看到实际状态。 |
| 用户明确停止制作 | 关闭新准入，区分“正在停止”“已停止”和结果未知；迟到结果不能自动关联回分析。停止不删除已保存产物。 |
| 请求退出 JuanerAI 或更新 | 有制作任务时提示等待其结束，或由用户选择停止后退出/更新；不静默终止活动任务。无活动任务则关闭属于内置版的服务。 |
| 服务崩溃、机器重启或强制退出 | 保留已持久化的项目与产物。重开时显示中断/未知，不自动重发模型请求或继续生成；显式恢复先检查权限、配置和在途记录。 |

首次接入不建设永久登录自启、后台守护服务或自动任务恢复。运行承载可以继续使用浏览器与同机服务；关闭浏览器标签页与停止本地产品服务是不同动作。

## 六 版本管理与数据保存

Report Studio 上游独立演进，JuanerAI 只携带经本版本验证的固定产物。用户可查看 JuanerAI 版本及实际插件版本；不自动拉取 Git 最新代码，不因为旁边安装了另一个版本就自动替换内置版。

首版随 JuanerAI 更新插件，不提供独立在线升级插件的入口。更新前确认没有活动制作或未知在途操作；存在时阻止切换，保留当前可用版本并说明需要等待或核对。新版本不兼容当前数据格式时，应在修改用户数据前拒绝更新或完成已验证的迁移方案；未经验证不得直接对现有数据运行旧版。必要迁移须保存可恢复副本并验证恢复，不自动扩大成历史独立版数据迁移。

内置版使用独立数据空间，与已安装的独立版互不接管。删除插件工作项目不应删除 JuanerAI 已接收的稳定报告副本；删除原分析后不自动删除插件项目，返回关联目标时明确目标不可用。用户主动删除某一侧数据的既有规则继续适用，首版不建设跨产品级联删除或自动双向同步。

报告在两侧分工明确：插件持有可继续编辑的工作项目；JuanerAI 持有已回传的交付副本与关联。保存本地副本不等于跨设备备份，内置模式不自动启用插件现有的 Git 数据同步功能。

## 八 验收标准

验收必须针对同一固定 JuanerAI 包及其携带的插件版本。工程检查、实际安装、真实模型制作、用户体验接受分别记录；本方案不预填任何 PASS。真实模型验证先使用获准合成材料，真实业务材料仅在另有有效授权时使用。

| 验收编号 | 场景与通过标准 | 对应改动 |
| --- | --- | --- |
| AC01 干净机安装 | 在声明支持范围内、无 Report Studio 仓库、无 Node/npm/Chromium 预装及无其他工具认证的 Mac，正常安装 JuanerAI 后可打开模块；无须命令行补依赖。 | M06/M07/M09 |
| AC02 完整主路径 | 选定分析成果，正确带入材料与来源，完成配置后真实生成 PPT、修改一页、导出、关联回原分析，并能下载同一交付文件；任务不依赖人工复制文件。 | M01/M02/M03/M10 |
