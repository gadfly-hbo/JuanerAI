## 3. 用户可点击的审核顺序

1. 默认打开插件弹窗 → 使用当前分析成果 → 选材料 → 打开独立标签的 Studio。首次使用在启动制作前审核可信本地说明及接受/仅查看，日常已接受场景不重复弹出。可改看“没有分析成果”“配置缺口”“授权缺口”“启动失败”。
2. Studio 中查看来源，切对话／成果，确认合成框架、选页、锁定、输入修改；品牌／场景、补充材料和历史入口保留。原型不理解任意输入，不读取附件，只展示安全文本和布局。
3. 成果页导出合成 PPTX → 已保存导出列表 → 关联回原分析 → 看到成功回执 → 返回原分析关联报告。再关联同一导出保持同一交付；继续修改后新导出产生新交付，原交付保留。
4. 顶部审核场景选择“回传失败／回执未知／导出失败／质检警告／工作项目已删除／来源更新／目标不可用”，检查下一步与内容保留；来源新版与旧版并存时，分别检查各行继续制作及详情，不互相改绑。再在关联 Studio 新建独立项目、返回宿主、点原报告继续制作，必须恢复原关联项目及已有编辑/导出，不能只聚焦停在独立项目的标签。
5. 选择“正在制作／结果未知／退出或更新／版本不可用”，检查停止范围、等待结算、核对和显式继续。不会用假百分比或定时器推进。
6. 从“打开报告工作台”进入独立项目，确认无来源、不提供关联回原分析，同时仍受配置／材料权限约束。

审核下拉与“推进合成状态”只帮助展示状态，不进入生产。专业模式链接指向原批准的完整样例，未变部分不重新接受；新增关联报告在专业报告阶段也须消费同一分析版本和交付记录，不能靠两个独立页面冒充接通。

## 4. 原型边界与访问性

所有页面持续标“合成审核，不是实现证据”；无 Provider、真实文件、真实下载、持久存储或后台服务。新标签间只传合成状态；独立打开时可通过返回链接查看固定宿主样例，不假称连接真实项目。刷新重置。示例项目名、数字、时间、版本均为合成，不作为用户业务事实。

宽屏1440×900、1366×768；390px仅做布局健壮性，不扩张移动交付。原宿主工作区、插件项目栏和按需详情保持；窄屏收侧栏、工具条折行、弹层不超视口。原生按钮、select、label、dialog；Tab 焦点可见，弹窗锁定焦点，Escape关闭并返回触发位置；状态有文字和 aria-live，错误保留内容。配置原型不接受真实密钥。

校验结果、已运行／NOT_RUN范围、来源身份见 [verification](verification-v0.2.md)。静态检查和原型截图不等于实际产品、干净机、编辑器、模型或用户 UI Gate 通过。若工具拒绝本地 file://，不另起服务或绕过权限，浏览器检查保留 NOT_RUN，由用户直接打开离线文件审核。
