## 中文优先文案

本增量附件面向初期中文用户：六阶段依次显示“新建分析、数据准备、本地处理、循证分析、分析报告、执行反馈”。“循证分析”沿用产品已有术语，意为基于证据的分析；阶段职能、顺序与业务行为不变。起点、工作空间、报告、专业视图、正式版状态及授权／人审文案均以中文为主。

专业概念采用“模型尝试（Attempt）”“事前预期（Expected）”“正式决定（Decision）”“分析收尾（Closure）”“分析发现（Finding）”“责任人（Owner）”“模型服务商（Provider）”“技能（Skill）”“提示词（Prompt）”的中文含义；界面不要求用户学习英文裸词。演示模型显示“演示服务商 / 合成模型”。品牌、SQL、Python、M1／M2、CNY、文件名及真实代码标识保持不变；没有引入翻译框架、依赖或视觉重绘。旧 accepted 附件及其原始文案保持历史原样，链接仍有效，不随本次中文文案修订。

## 首条正常路径

1. 在空白任务输入问题，或选择示例后点击“开始这项分析”。示例不会直接执行。
2. 文件入口在首次点击前直接说明：只检查所选资料的本地格式、角色、字段及覆盖，不授权计算、模型使用或外发，不读取其他目录。点击“添加两份合成示例文件”只是预置演示操作，没有真实文件选择器。
3. 查看任务授权：目的、两份资料、期间、PAID 演示状态、复购定义、本地操作、模型出站类别、演示服务商 / 合成模型、额度／终止条件。自由文本确认默认未勾选；明确勾选后开始。
4. 五个合成步骤连续推进，每步约 1.4 秒；无需逐节点继续。顶部“停止”始终可达。切到专业模式不会停止任务。
5. 查看系统验证结果与待审报告：两期活跃会员均为 200，复购会员 100 → 80，复购率 50% → 40%，差 −10 pp；复购收入 CNY 20,000 → 16,000。原始行和业务身份不展示。报告回链展示预置主算／复算一致结果。
6. 对报告某一节填写点评；输入框即提交前的完整文本预览。“让本次 AI 使用这条点评文本”默认未勾选。未勾选只存本地，不分类、不改报告、不重算；勾选后才模拟处理。简短表达追加版本并保留数字／来源；期间调整请求新授权；新客筛选、因果判断说明能力边界，不派发任务。初次授权不笼统包含未来点评，重新授权的文本预览排除未选点评。
7. “审阅结论与下一步”显示有限 Finding 及合法 Closure：正常路线展示至少两个完整固定合成候选，各含行动、证据、条件、反证和预期，至多一个有理由偏好；这些候选不是新增生产候选。填写审阅人，选择 C1／C2／不行动／暂缓。候选 Expected 先展示来源清楚、尚待人确认的建议摘要，复用已有候选、事实和数据边界；用户明确未知的方向、目标、时段及 Owner。完整字段和现有护栏可展开编辑，也可不用建议。适用字段缺失仍不能提交；不行动／暂缓保留 N/A 原因、责任和复评触发。明确人审成功才追加 final 报告及正式记录，没有业务行动权限。

## 场景回放

顶部“评审场景工具”属于附件评审设施，不是产品操作。选择条件并确认重置后，仍须从输入任务、资料、授权开始；不会跳过用户按钮。重置只清空本页内存。

| 场景 | 应观察到的结果 |
| --- | --- |
| 正常下降 | 系统验证与待审报告先出现；Finding 尚未人工接受。 |
| 实际未下降 | 100/200 → 100/200，50% → 50%，收入 CNY 20,000 → 20,000；明确不支持下降前提。 |
| 单期零分母证据不足 | 比较期活跃会员200、复购100、复购率50%、复购收入CNY20,000；当前期活跃0、复购0、收入0。双期合计仍有有效行，当前率不可计算、率变化N/A，M2不适用，不伪造0%或率下降。最终只接受有限不足，Closure走有理由、无偏好的不足路线；无候选选择，可补证、仅保存限制或明确不行动／暂缓。 |
| 双期合计无有效行 | 两期筛选合计0有效行，在本地资料准备处阻断；不启动分析／模型报告，不产生Finding、Closure或final。说明应补充覆盖资料或明确合法期间，不擅自猜测。固定空数据回放停在此处。 |
| 匿名分组 | M1 + M2，A 收入差 −3,000，B −1,000，总体 −4,000 CNY。没有原因或策略有效推论。 |
| 缺少订单 | 首次添加只得到会员资料；不能授权计算。用户补充合成订单后才可继续。 |
| 期间语义缺失 | 展示 member-repurchase-context v1、已确认会员／订单角色、PAID 状态映射、CNY 与时区；只问真正缺失的期间，不要求重填整套问卷。 |
| 主算／复算不一致 | 不产生本次已验证 Finding 或报告；保留资料与口径。用户点“继续未完成工作”后，后台先核验原任务 grant 的来源、范围、期限和剩余额度；仍有效则沿用，同 grant 下产生新 Attempt，失效才重新授权。 |
| 模型失败 | 已验证本地结果保留，报告未完成；失败只结束 Attempt，不自动撤销 grant。用户明确继续后，后台核验，仍有效直接复用原授权，没有每 Attempt 重复审批；没有自动重试或偷偷换模型。恢复只重做最后报告步骤，保留旧 evidenceAttempt／有效 G1，不重算。 |
| 停止／关闭重开 | 在运行时点停止，或关闭任务并确认；计时步骤终止，不会迟到复活。重开仅恢复视图，继续要新授权。 |
| 点评改期间 | 原 8月1–7日 vs8–14日，可改 8月8–14日 vs15–21日。新结果 80/200 →90/200，40%→45%，收入16,000→18,000。原报告只读保留；同值保存为 NO_CHANGE，不使当前结果过期或重算。 |
| 最终发布失败 | 勾选评审工具“下一次正式记录模拟失败”，正常填写确认并提交；全部正式效果均未生效，表单草稿保留。提交锁定，必须先读回；直接重开最终审阅也不能绕过。读回未生效后才能显式重试并重新确认，成功只追加一次。 |

故障恢复由“继续未完成工作”显式触发，固定回放假定下一次故障条件已解除；不声称真实系统自动修复故障。后台核验失败时不能悄悄扩权限。恢复不重置累计资源：每合成步骤记演示值 CNY0.05，任务示例上限CNY1.20、12步；不足所需步骤时阻止继续。新分析需5步，明确选择后的点评分类需1步，复用有效G1后仅恢复报告需1步。没有实际付费、模型调用或费用控制证明；数值不是生产默认或真实费用。

Attempt终结与任务授权分开：成功产出待审报告或发生失败后，原 grant 仍可能有效。失败后的显式继续先作后台核验，不因创建新 Attempt 就要求新授权。演示 grant 在确认时记录15分钟有限截止；这是原型示例，生产期限仍待确定，且与单 Attempt 的60秒限制不同。用户停止、显式关闭、App重开、过期或实质来源／期间／范围改变仍封闭原授权；继续需要重新授权。每条新点评仍须选择文本，旧点评默认不再次外发。期间变更仅绑定触发变更的一条点评及原需求。取消／Escape清除未提交意图，不启动工作；不会自动恢复或清零消耗。

## 人工判断的三种结果

- “记录选择并完成审阅”：接受所列有限 Finding、完成展示了完整内容的合法 Closure、记录 Decision / Expected、追加 final 报告。候选需完整结构化事前预期；不行动／暂缓需 N/A 原因、责任人及复评触发。零分母不足仅接受资料限制，且不提供候选偏好。不会执行行动。
- “只保存分析结论”：审阅人明确接受所列 Finding、完成 Closure、追加 final 报告；不创建 Decision / Expected。
- “需要更多证据”：保留待审报告及补证状态；不接受 Finding、不完成 Closure、不创建 Decision，也不假称已经完成产品判断。

无勾选或字段缺失不能正式记录。未知点评仅留记录并请求具体意图，不改动报告事实。历史报告中的数据、期间和正式判断是当时快照，不随当前状态变化。

最终审阅的 Expected 与 N/A 字段按当前选择显示，选择变化只切换已有控件显隐，不重新渲染或清空用户填写内容。“只保存分析结论”不要求决定／预期字段。候选预期同时包含观测对象、带来源基线、不确定性、评价触发与依赖、独立的可编辑Guardrails护栏。护栏必须明确填写约束／停止条件，或由人明确N/A及原因；不能留空、只写N/A或拿依赖代替，保存后进入正式报告可回读。源证据说明观测对象是两期活跃会员；C1反馈基线固定显示unknown及未采集理由，不把40%复购率冒充反馈基线。C2仅在同口径指标下引用本期复购率，其他指标明确unknown。已有证据与限制提供可读摘要，未知Owner、目标和观察时段仍由人明确。保存候选不会产生Actual。

Expected 默认展示有来源的待审摘要，复用配置／已有候选含义／本次证据和边界。完整建议及现有护栏放在可展开编辑区，没有新增护栏对象或审批。可修改，也可点“不用此建议”保留自己的输入后重新填写；缺少适用字段时展开缺项，不绕过合同。C1／C2切换各自保留本轮输入。任何预填文字都是有据的合成建议而非用户已确认事实；目标、方向、期限、Owner等未知值不预设。

计划准入／实际执行前／结果发布前的三处检查、预算记录、整体正式提交一致性属于后台责任，不增加普通用户审批步骤。前台保留已有最终一次明确人审。M1-only确实不执行M2须由真实工程验收证明；本附件的显示或预置进度不构成该证据，也不新增内部操作按钮。

本演示的模型数据材料仅限获准总体摘要。M2匿名组级数值、组级Finding及含组值的点评／报告段落只在本地确定性报告中绑定和显示，尚未批准外发，模型不声称读过；匿名化本身不构成小群体披露许可。小群体／屏蔽规则仍待关闭，本次不另设审批表单。

场景重置显式清空Expected草稿缓存；合法新期间正式采用时同样清空finalDraft、expectedCache与expectedChoice。旧报告／点评继续保留原来源绑定，旧Expected不会自动变为新期间的待审草稿。

## 存储、执行和验证边界
