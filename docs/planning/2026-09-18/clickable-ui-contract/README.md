# Xanthil Desktop Clickable UI Contract v1.0

## Purpose

This is the high-fidelity clickable product contract for the first Xanthil
Desktop Free vertical slice. It is a local static prototype for the user UI
Gate, not production software.

All files, identities, calculations, model calls, persistence, recovery and
exports shown in the prototype are synthetic and simulated. The prototype does
not read local files, access a provider, call a network API, start a database,
or persist a Decision Case.

## Covered product behavior

- six-step membership-repurchase Decision Case;
- local-data authority and import-issue confirmation;
- fixed H1, judgment rules and analysis-plan review;
- optional model disclosure with a complete manual path;
- simulated Run progress, cancellation and retry;
- evidence, refutation, limitations and Finding acceptance;
- candidate comparison or insufficient-evidence closure;
- Completed, reopen, rerun and export interactions;
- all thirteen required failure and recovery classes;
- dark and light themes, keyboard-visible focus, 1440x900 and 1366x768 layouts.

## Gate boundary

User UI Gate acceptance may freeze product interaction input for a later
OpenSpec Change. It does not prove production computation, persistence,
security, Runtime, provider, packaging or release readiness and does not
authorize implementation by itself.

The browser entry is [`dist/index.html`](dist/index.html).
