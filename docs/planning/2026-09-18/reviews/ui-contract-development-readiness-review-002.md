## 1. What I Would Build

A high-fidelity, explicitly simulated and labeled Xanthil Desktop Free
experience, not production software, for a non-technical membership-operations
analyst to complete one six-step membership-repurchase Decision Case. It covers
local-data authority confirmation, CSV import and quality review, fixed H1 and
plan confirmation, simulated primary and independent computation, evidence and
judgment review, Finding acceptance, candidate or insufficient-evidence closure,
reopen, rerun, export, and every specified recovery state.

The surface remains decision support: “优先验证” is not approval or Action;
Action execution and Outcome are outside the slice.

## 2. Required Guessing

None that is load-bearing for the clickable UI Contract. The package fixes the
slice, data boundary, H1, calculation and judgment rules, Case and Run states,
history semantics, optional model interactions, failure recovery, closure
guards, and observable UI Gate scenarios.

Visual styling, component choices, synthetic example values, and simulated
provider presentation remain design choices only when they preserve the written
semantics and visibly identify simulation.

## 3. External Study Required

None. The written adoption bullets are the complete binding Demo-derived input;
unstated Demo material is not a requirement.

## 4. Untestable Requirements

None for the clickable-UI Gate. The five UI Gate scenarios cover positive,
