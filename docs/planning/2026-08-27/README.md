## Purpose

This package replaces the active product-roadmap role of the frozen 2026-08-23 CLI-first package while preserving that package as history. It unifies two mutually constrained plans:

- Xanthil becomes desktop-first for macOS and Windows and first delivers a product-manager-style static Demo for review before productization;
- the Data Analyst required workflow is completed before Model Pack product work starts;
- the former peer “four-library” map is replaced by Data + Ontology foundational authorities, Hypothesis + Strategy long-term assets, Domain Pack + Model Pack executable capability packages, and Knowledge + Memory background capabilities;
- the two-phase Model Pack product direction is retained, with Xanthil Desktop replacing the CLI/Personal consumer.
