**后续状态：**用户已在本chat通过既有v1.1 UI审核；本次仅依[产品输入§1.1](product-input-v1.1.md#11-2026-10-05-用户确认本地计算保留明细零外发延期)更新快速材料／授权文案，既有视觉和其他交互不重做。主任务允许获准明细、严格零外发延期是用户已确认的产品决定；本次修改的具体可见文案仍随候选供核对，不把历史UI接受外推为整包冻结、工程恢复或真实模型验证。

## 1. 来源与设计原则

布局／组件／信息层级沿用PX-006快速及双模式、PX-004专业完整六阶段，字节身份见[source-manifest](source-manifest.json)。没有替代产品、七段新页面或暗色改造。新审核页复用原PX-006 CSS及JuanerAI brand.css；专业区域加载保留PX-004完整参考，iframe仅审核隔离实现，不规定生产框架。

设计原则：①对话主线，分析成果可检查；②快速减操作负担，不减专业性；③默认摘要、按需深查；④只在歧义／权限／正式判断打断；⑤真实记录与合成审核严格分开。中文优先，JuanerAI字标＋“持续做出更好的决策”，无图片Logo。保留绿色主动作与白浅灰工作台，不新增装饰色体系。

## 2. 审核入口与具体看法

打开[可点击v1.1](clickable/v1.1/index.html)，默认正常**合成审核样例**，持续横幅说明无后端／无模型／无文件执行。审核工具条不属于生产；可选择正常任务、起步空态、缺信息、前提错误、正在执行、执行失败、已停止、重开、UNKNOWN和范围修改。固定按钮切换状态，**没有定时器伪执行、真实文件读取或下载**。自由输入只体现消息位置与“审核稿不理解任意文本”，不按关键词假装AI。

可检查路径：打开“业务理解”→“分析方案”→“图表／证据”工作区；用“查看范围修改”比较旧／新版本及失效影响；选Skill／Prompt；打开Fork或Subagent独立对话、回流待审／采纳／拒绝；查看授权差异及变换预览；打开报告与人审摘要；切专业保留004六阶段。返回空态只清审核内存，不代表产品重置／删除项目。

## 3. 可见行为（Q11-01～12）

| ID／位置 | 行为与验收边界 |
| --- | --- |
| Q11-01 左会话＋中央对话＋右抽屉 | 延续006布局、项目／搜索／能力条；普通入口自然提问，不先选行业／会员模板。搜索当前有权限项目的真实会话，跨Case资产检索不冒领N08 |
| Q11-02 需求理解卡 | 摘要目的／对象／范围／交付；区分用户原话、资料事实、假设、建议、未知；可展开或自然语言修改。已明确项不重复问 |
| Q11-03 分析方案卡 | 简要问题、方法、输入、关键前提、预期成果；点开工作区看对应逻辑。可改范围／口径，业务变化生成新框架／计划并标影响，表达变化不重算事实 |
| Q11-04 真实进展 | 一个轻量摘要／状态点，实际执行／等待／核验及回到先前工作可见；不是每题必经五步导航，不给虚假百分比。可展开工具事件，不展示模型内部思维链 |
| Q11-05 辅助抽屉 | “口径／方案／资料／证据／执行”按需切换，指向同一任务／版本；显示语义来源、绑定、单位／时间／冲突、授权和排除。内部IR／代码身份在高级详情，不强迫用户阅读JSON |
| Q11-06 展开工作区 | 在同一主区放大框架、口径、表格／图表、报告／证据，保留返回对话与当前上下文；窄屏抽屉覆盖，不压成三列小字。不是新常驻审批窗口 |
| Q11-07 文件／材料／变换 | 支持已列格式；快速主任务所选业务明细可按有效许可供模型读取，本地工具实际处理与计算，严格零外发延期，不能仍写“表格明细不进模型”。资料详情及授权说明区分模型可见材料与本地执行范围，后台复用有效授权，只处理真实差异，不逐字段。前10行Diff可检查后全量派生，预览与全量绑定同一受检转换身份、原件不改；缺失映射／行级异常明确部分完成或失败，不静默保留原值后称成功。不可解析／能力未就位如实反馈；需要零外发保证的任务明确缺口而不静默上传 |
| Q11-08 Skill／Prompt | 选择可查看用途／版本／要求，Skill实际改变计划或工具步骤，Prompt改变表达而不改权限／口径／核验。打开入口不等于安装；方法选择不自动执行未授权工具 |
| Q11-09 Fork／Subagent | 保留独立子对话、来源、材料精确子集、任务／状态／停止／恢复；人工发起、单层顺序，不自动派发／采纳。回流是待审MODEL意见，不是新的独立计算证据；明确采纳仅关联材料，不自动改正式Finding／Decision |
| Q11-10 报告／判断 | 证据事实／未核验探索／模型解释分别标明；报告点评区分表达／重算，旧版本保留。会员保留仅确认分析／要求补证／记录决定及Expected护栏；开放本轮停止推进与交付规则见产品输入OA-08，成果保存与版本判断分别显示，认可不产生final／Completed／会员Closure或自动决定。失败／UNKNOWN不显示认可成功；后端保存／下载请求／落盘分别表达 |
| Q11-11 生命周期 | 保存等后端回执；停止显示受理／结束／UNKNOWN，阻断后续与迟到正式发布；关页不是停止。刷新只读，重启不续跑，显式继续核验已有授权并只做缺失部分，计量／重试不清零 |
| Q11-12 失败与修改 | 缺信息指明业务问题与原因；错误前提可纠正后继续；失败保留有效成果／原因；UNKNOWN只能读回／核验，不能用继续盲目重发。新范围显示版本diff和失效项，不误导“已修改报告＝已重算” |

生产所有状态、引用、工具事件、保存与人审都必须来自真实后台。审核样例、脚本按钮及图表不是实现证明；未接通处不得填合成成功。**内部首试可以少量入口，但首版完成不得用全部快速能力空置交付**；真实资格／权限不足的具体任务仍可诚实停下。

## 4. 快速／专业及历史延续

同一产品任务、语义、计划、授权、报告和历史；切换不执行、不生成新Session、清账或变更控制权。专业六阶段使用PX-004完整交互而不是006占位，保留其假设／证据／子任务／报告／反馈位置。当前审核专业页是来源合成回放，横幅明确，**不伪称它与新增开放样例已在后台共享状态**；生产该对应必须实际验收。

专业反馈空位置不授权Actual／现实行动／资产学习。旧001～004功能优先接线；005有实现证据但未正式完成，新界面不改历史接受或旧E2缺口。UI可随开发修订，对受影响实质行为取得用户接受，不将v1.1永久冻结或允许Mini自主重画。

## 5. 状态、可访问性及验证

- 状态覆盖见§2；缺信息、失败、未核验、已停止、UNKNOWN以文字＋语义色表达，不靠颜色。组件保留明确名称、可见焦点、Tab／Escape和返回焦点；输入文字用安全文本，不当HTML执行。
- Desktop审核1440×900、1366×768，兼顾窄屏390px与长内容；主对话与展开成果各有合理滚动，工具条换行，抽屉按需覆盖。移动是附件健壮性检查，不新增生产移动端交付。
- 静态资源／语法／链接／来源身份、合成边界及禁止网络／持久化调用在附件检查。实际浏览器视觉／点击只在获准本机静态预览中进行，不启动产品服务；未获许可或工具不支持如实NOT_RUN。
- 用户UI Gate、独立产品就绪、实际业务／安全验收、工程接受、Git与恢复各自分开。新增三核心行为不得用旧Review002或静态检查宣称PASS。
