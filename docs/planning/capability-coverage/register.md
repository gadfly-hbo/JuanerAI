## 读法与基线边界

- 本清单将蓝图要求与累计事实放在同一处。各项的“目标／完成条件”是对所引蓝图的可观察释义，不批准新的业务细节；尚未定义的场景、阈值或权限明确留在缺口中。稳定 ID 不因 Change 或文件改名而变化。
- 状态含义沿用唯一政策：未启动、规划中、实现中、局部实现、目标范围已验收、待核验。**已验收子范围可以属于仍局部实现的能力**；不同能力使用自己的条件，没有统一成熟度评分。
- 每项分开写“方案、代码、接通、验收”。代码入口或规划存在不是实际运行证据；“接通”明确是原生真实组件、替身还是接收方转述。合成数据上的真实执行不证明真实客户效果。
- 证据截止：首版回填时本地基准为 `5a8fe7b38ebdb1c2a8d49dcb5bdc5fa9d4bc3041`；003完成状态依据已读回的GitHub固定版本 `2bb18d7356289781a87a672dc3f7b9bd40341d87` 的验收／归档文档及Mini回执，见 [E-003](evidence.md#e-003)。采集时未同步产品代码；后续文档发布不将这些历史证据变为持续在线状态。各项更新时间指证据判读日期，**不是原验收日期**。
- Change001～003 的原验收保留；本次没有补做产品验收，也未读取 Mini 原始证据文件或重跑测试。旧 CLI/Core/Pack 资产尚未逐项核验，不因资料不足判为不存在；使用 [E-LEGACY](evidence.md#e-legacy) 标注。
- C5-08按蓝图§6.2的有界Case Assistant范围记录已验收；C5-03/04按§6.3的单层Fork/Subagent范围记录已验收。均不代表其他业务场景或通用Agent平台完成。其他宽目标不因一个会员复购场景通过而变为完成。
- 每个条目的关联 Change 是贡献／计划关联，不是能力的私有所有者；共享 A/B 证据可复用，不重复计作多个完成结果。无业务增量的开发热更新支撑见 [E-DEV](evidence.md#e-dev)，不提升产品覆盖状态。
