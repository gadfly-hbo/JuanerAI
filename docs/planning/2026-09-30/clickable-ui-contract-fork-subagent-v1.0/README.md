# Fork / Subagent 可点击 UI Contract v1.0

这是 Change 003 已获用户 UI Gate PASS 的产品规划附件，使用合成数据及确定性场景；不是生产实现或真实模型验证。2026-10-01 用户“审核通过”及冻结身份见[批准与产品输入冻结记录](../xanthil-fork-subagent-approval-and-product-input-freeze-v1.0.md)。正式范围见同日的产品计划与增量 UI Contract；可点击实现字节未因批准而改变。

## 打开

为使独立父子窗口共享同一来源的合成状态，推荐在仓库根目录启动仅监听本机的静态服务器，无需安装依赖：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory /Users/huangbo/.codex/worktrees/e1d5/JuanerAI
```

打开 [父对话](http://127.0.0.1:8765/docs/planning/2026-09-30/clickable-ui-contract-fork-subagent-v1.0/index.html)。可换空闲端口；父子窗口必须使用同一个协议、主机和端口。`file://` 可预览排版，但不同浏览器对本地文件的跨窗口存储行为不同，不作为回流验收入口。

创建会调用 `window.open` 打开同一 `index.html?child=F-01&session=<合成实例>` 或 `?child=S-01&session=<合成实例>` 的独立浏览器窗口；浏览器可能按偏好显示为独立标签页。被拦截时，父页面显示明确的“打开子对话”链接。允许本机站点弹窗可获得桌面双窗口呈现。左栏节点再次选择已有命名子窗口时仅聚焦、不重载；它不是父消息流里的内联伪子任务。

每个子节点下方始终提供带真实地址的“在独立窗口打开 … ↗”链接。内嵌浏览器即使返回了 Window 对象，也可能没有呈现子窗口；此时使用该链接，在独立标签页打开确切 URL。正常切回已打开子窗口仍使用会话树按钮。

## 首次回放

1. 初始父对话是 P-01，关联当前 Completed Case r7，父 Attempt 已终结。下方 Fork / Subagent 入口可见。
2. 点击 Fork，选择历史截点、勾选截至该点的具体历史／聚合／报告，填写目的。取消后没有子对话。确认后打开独立 F-01；此时只创建对话，仍待授权。
3. 在子窗口点击“查看子任务授权”，核对逐字文本、历史、精确聚合身份、报告摘要、Provider / Model、五项只读能力、排除项和演示上限；勾选敏感文本确认后开始合成 Attempt。
4. 右下角展开“UI Contract 场景”，选“子任务 Waiting / 追问”；在子窗口回答，再选“子任务完整成功”。这些按钮由评审者明确推进，不伪装成真实 Provider。
5. Fork 下方出现完整结果，父窗口尚无结果。点击“选择此完整结果回流”，父窗口出现一个待审项。继续分支可创建新的已授权 Attempt，完整结果使用新身份，旧结果保持。
6. 父窗口查看确切来源后，采纳为父对话材料或拒绝。采纳仅增加 MODEL 材料，右栏及专业模式仍是 12 / 4 / DR-002 / EO-002 / v2。
7. 点击“继续父对话 · 新授权”，逐项选择已采纳 MODEL 材料并确认；新父 Attempt 的历史面板列出选定结果 ID。未采纳／被拒绝材料不出现在可选列表；未勾选材料不外发。
8. 终结父 Attempt 后创建 Subagent；授权并触发完整成功，结果自动回流为待审。子窗口显示已回流；没有多余的手动成功回流按钮。

### Fork 从 R1 继续到 R2

1. 在 Fork F-01 完成首个合成 Attempt，保存 `F-01-R1`；可先回流 R1，也可仅保留在子窗口。
2. 在子输入区填写下一轮目的，例如“基于 R1 进一步区分限制与建议”，点击“继续分支 · 新授权”。
3. 授权窗口逐项列出自身已保存用户消息、模型消息、只读回执及完整结果版本，全部默认未选。只勾选 `F-01-R1`，下方精确预览显示 R1 身份、来源 Attempt、类别与全文；未勾选的消息与回执不加入。
4. 检查仍显式列出的父分叉继承历史、数据和报告，再确认自由文本外发并开始新 Attempt。右栏“历史”显示该 Attempt 的 `已选自身历史 / 结果：F-01-R1`。
5. 推进新 Attempt 成功得到 `F-01-R2`；R1 保留原身份与处理状态。可手动选择 R2 回流，不会覆盖 R1。
6. 若旧 Attempt 中途停止，其已保存文本仍可逐项选为“历史（不是成功结果）”；它不出现在成功结果卡或成功回流路径。更改历史选择会清除敏感文本确认，须重新确认当前预览。

Waiting 时在输入区发送当前可见回答，表示用户确认该文本仍在当前 Attempt 的原授权范围内；消息记入同一 Attempt。界面持续说明：新增数据、工具、来源或限额须先停止，再开新授权。回答不自动加入其他历史、材料或新权限；来源、模型或硬上限失效则阻断发送。

## 失败与恢复回放

| 场景 | 操作和可观察结果 |
| --- | --- |
| 父 Running / Waiting 或接入占用 | 场景面板设状态，点击 Fork / Subagent 或子窗口授权，明确阻断，不隐式停止或排队。 |
| 模型未配置／预算缺失／拒绝外发 | 切换场景后打开授权，开始禁用；取消不产生 Attempt；恢复配置后须重新授权。 |
| 子失败、停止、超时、预算耗尽 | 活动子 Attempt 上触发对应场景；状态终结，没有该 Attempt 的成功结果或回流。 |
| 部分文本 | 活动子任务触发部分文本，仅历史可读，不可回流。 |
| 迟到完成 | 先停止或关闭子任务，再触发迟到完成，拒绝恢复运行或补出成功。 |
| 自动回流失败 | 子任务成功前设“下一次回流失败”；成功结果留子窗口，父无卡；重试回流只做本地处理。 |
| 重复回流 | 已回流后触发重复回流；父卡、结果身份和材料不重复。 |
| 采纳保存失败 | 先设“下一次采纳失败”，确认采纳出现错误；待审保持、材料无半成功，再次确认可重试。 |
| 来源／决定变化 | 从另一窗口触发 r8 或 DR-003 场景；旧结果可读、显示过期，回流／采纳／外发阻断。已打开采纳确认也在提交时复核。 |
| 审阅中来源资格失效 | 父窗口打开采纳／拒绝确认后，在子窗口触发“来源资格不足”；回到确认提交再次检查资格，显示缺少有效 Closure，结果保持待审，材料不增加。 |
| 父后来追加消息 | 触发父新增消息；现有子的继承快照不增加，不因此自动过期。 |
| 视图导航 | 切换专业／快速模式或返回父窗口；任务保持原状态。 |
| 关闭子窗口 | 产品控件“关闭并停止”先确认；浏览器原生关闭／刷新活动窗口会请求浏览器退出确认（浏览器策略可能限制），取消不变。实际离开在 pagehide 将子活动 Attempt 标为 Interrupted。再从父树打开，历史保留，新运行需授权。 |
| 关闭父会话 | 确认后活动父子 Attempt 全部 Interrupted，历史与成功结果保留；父任务没有后台续跑。 |
| 应用重开 | 根页面刷新或触发模拟重开：Running / Waiting → Interrupted；成功但未回流的 Subagent → 待回流恢复，用户显式重试，没有自动执行。 |
| 越界与递归 | 场景明确拒绝未选历史、原始行、其他 Case、任意文件、网络和下级任务；界面无执行这些能力的路径。 |

来源变化后的新 Case Assistant 重新关联及正式记录修订仍属既有流程，本增量只展示旧子历史保留和阻断，不把旧材料重绑 latest。场景面板重置用于重新开始另一条独立回放，不代表产品重绑。

## 合成持久化和重置

仅写当前浏览器来源的一个键：`localStorage["juanerai.ui-contract.fork-subagent.v1.synthetic"]`。其中只有本附件合成父子身份、任务文本、选定历史、Attempt 状态、成功结果、回流／采纳状态及场景开关；不读取或写入生产 Session、模型配置、授权、凭证或业务数据。不要在此原型输入真实敏感内容。

使用右下角“重置此附件全部合成状态”，确认后仅替换这个键；其他来源、其他附件和文件不变。先关闭所有子窗口，回到父页重置。旧子 URL 在重置后显示不存在并阻断运行；从新父流程重新创建。建议一个根窗口及其命名子窗口完成回放，避免把多个根页面当成多个产品客户端。

本页使用 `storage` 事件读回其他窗口变化；监听器只注册一次，单个点击只提交一次状态；结果 ID 守卫防重复回流和重复材料追加。页面没有定时自动完成，已停止任务不会被晚到计时器复活。HTTP 仅用于读取本机静态 HTML/CSS/JS/PNG，CSP `connect-src 'none'` 阻止运行期连接；无 fetch、XHR、WebSocket、Provider、业务 API 或文件写入。

这不是跨进程事务、真实崩溃耐久性或工程幂等证明。浏览器存储、`beforeunload` / `pagehide` 与弹窗策略不能替代后续 Application / Adapter / 原生桌面验收。演示费用上限和等待时间不是批准的生产阈值。
