## 2. 已确认的产品顺序

长期理念仍是“持续做出更好的决策”。C端指有真实业务任务的专业个人；先证明一类本地可信分析的价值，再向团队和企业扩展。

| 顺序 | 产品工作 | 需要获得的证据 |
|---|---|---|
| 随第一步建设 | 最小共享Contract、Context/Binding、IR、证据和Case引用，复用既有内核 | 首个任务可持久化、恢复、核验；不先建设全产品平台 |
| 1 | **Xanthil Desktop Free**：个人真实分析闭环 | 能独立完成一类声明支持的任务，查看计划/代码/证据，保存、重开、复跑和导出 |
| 2 | 个人重复价值与P1复用能力 | 首次价值、有效任务、重复使用和资产复用；观察留存与实际协作需求 |
| 3 | **JuanerAI Workspace**：团队共享、复核、版本与资产迁移 | 多人复用、可追溯审核、正确权限和团队付费价值 |
| 4 | 一个企业业务场景试点 | 有限数据与明确问题，贯通建议、审批、行动、独立回执和结果观察 |
| 5 | **JuanerAI Enterprise**：企业治理与规模化 | 企业连接、语义、权限审计、运行保障及可审查业务价值 |
| 条件性远期 | 限定领域的受控自动行动 | 证据与风险满足约束，按动作和范围独立授权，可停止、接管和适用补偿 |

Xanthil CLI是专业伴随入口；JuanerAI Packs横向服务上述形态。Workspace承担团队能力层，但不是每个企业采购方必须先购买个人套餐的渠道限制。Model Pack两期是独立专项路线，不被个人留存或Workspace完成设为新的启动硬Gate。

## 3. 与原文及既有边界的对齐

| 融合点 | 本版采用方式 |
|---|---|
| 免费入口与商业增长 | 个人版提供完整可用价值；云模型/服务/硬件成本单列。团队与企业为共享、治理、执行和规模价值付费；转化效果仍待验证 |
| Enterprise清单包含DAME、语义和Pack | 解释为组织范围增强。个人端从第一阶段就具备最低方法验证、业务语义、证据和数据保护 |
| 共享约20类核心对象 | 保留语义目录，并补明既有Contract、Context Bundle/Binding与IR关系。不是先冻结20套Schema或新增一套内核 |
| Decision Case | 作为可审查的业务案例与精确引用集合；不新增执行契约、权威库或自动批准的策略。迁移包格式和重放条件待具体合同 |
| 三种Workspace作用域 | 与JuanerAI Workspace团队产品、Model Pack生命周期工作区分开定义；个人批准不升级为企业执行授权 |
| 六类Packs商业目录 | 映射到Domain/Model、Port/Adapter和Owner治理。Strategy/OSM模板不自带业务有效性，Connector不带客户凭证，Governance/Skill不自授权限 |
| Stage 0和P0/P1/P2 | 最小定义随首个纵切建设；产品目标与正式冻结范围分别登记。不能以新增清单删除既有Fork/Subagent、报告锁定等要求 |
| 至少两个决策候选 | 适用于决策支持任务；证据不足应说明，纯清洗可说明不适用，不为达到数量编造备选 |
| WVAT | 用户确认工作价值的每周真实任务指标，区别于技术PASS、因果增量与发布许可；资格、去重、窗口和撤销口径待验证计划明确 |
| 迁移、遥测和模型调用 | 分别授权；不默认汇集原始数据、个人历史或企业专属资产。API Key/连接凭证不随业务资产包导出；目标侧重新配置访问 |
| 自动学习和自治 | 反馈保留支持/否定/未知，按Owner形成候选和回归，经批准发布后显式采用；购买Enterprise不获得自动行动权限 |
