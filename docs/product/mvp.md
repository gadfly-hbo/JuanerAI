# Xanthil Desktop Productization Readiness

## Confirmed

- Product: Xanthil Desktop for macOS and Windows.
- Parent project: JuanerAI.
- Primary user: Data Analyst.
- Role: evidence-bound Data Analyst assistant and foundation for later decision support.
- Current executable baseline: approved Pi-backed CLI local-analysis slice, reused only through named Product Core/Application/Port/Adapter/Profile contracts.
- Product loop: Data -> Decision -> Action -> Outcome.
- Delivery direction: local-first and enterprise-ready.
- First product artifact: static Desktop Demo reviewed before productization.
- Required product workflow: Data preparation, local cleaning/aggregation, Evidence-based Analysis (循证分析), report output, and execution feedback.
- Product order: Model Pack starts only after `DA_REQUIRED_COMPLETE` and explicit user authorization.

## Not Yet Frozen

- Static Demo product decision.
- Desktop technology and packaging.
- User-provided local Python processing proposal and approved TypeScript/Python boundary.
- Project/Session persistence, identity, retention, deletion, recovery, and migration.
- Fork/Subagent Runtime, sandbox, concurrency, cancellation, and merge behavior.
- Skill/Prompt administration and version authority.
- Exact first Change, real Windows acceptance environment, compatibility, activation, and rollback.
- Real-model/provider and data-egress contract, if any.
- Whether the first productized slice is asset-reference-only or may create draft candidates.

## Entry Gate

The current planning candidate must pass a fresh Development-Readiness Review and explicit user approval. The static Demo must then be reviewed. Before the first behavior-changing Desktop Change, the D0.5 productization decisions above must be resolved or deferred behind an explicit stop line; no implementer may invent them.

## First Change

No Desktop Change is authorized by this readiness document. After D0.5, the Controller selects the smallest Application-led end-to-end user-valued slice, records exact reuse/delta and acceptance, and returns for explicit product Change authorization.
