# 089 / AU-01, AS-04, AC-03：提交前目标复核

原生主 Agent 在已授权执行中结束一轮，不等于业务目标完成。真实126取得六项算术凭证，却未取得原需求明确要求的独立调查意见；部分报告与失败历史保留，不能判为 AS-04 通过。

执行阶段的原生主会话在准备交付前，进行至多一次目标复核模型步骤：消费原始需求、当前真实计算数量及真实协作返回状态，使用同一会话、工具集合、授权、身份与持久账本，自主决定补查、委派、等待必要信息或交付有明确限制的成果。不得按中文关键词强制派发、指定 Agent 数量或层数、自动造反证或由后台代写调查意见。复核不是另一次故障重试，不清账，不扩权限；只有实际合法的工具调用才产生效果。已待澄清、撤权、取消、旧报告恢复和准备阶段不启动复核。复核后再次结束不得形成无限复核循环，缺口仍真实保留；未满足实际验收不得声称完整完成。

场景：模型在核算后过早结束；下一步必须收到目标复核，并能自主选择独立调查工具，实际回流被后续模型消费。场景：简单任务无必要协作；复核允许直接结束，不产生子任务。场景：复核前撤权或显式停止；不得发出下一请求或保存新成果。
