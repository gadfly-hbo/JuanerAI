## Data, authority, and security boundary

- User-selected source bytes remain local. Confirmed copies in 010_draw are the
  raw snapshot authority.
- DuckDB/Python produce deterministic analytical evidence; verified aggregate
  bytes in 020_clean and the terminal Desktop Run 3.0 bundle are calculation
  authorities. SQLite adopts that evidence only through a committed Succeeded
  row with exact run locator and version; unreferenced bundles remain inert.
- SQLite owns operational relationships, state, current references, history,
  and command receipts; it is not raw or analytical authority.
- Application is the only semantic writer. Main transports validated commands;
  the Renderer displays projections; Adapters report physical results.
- Pi receives only an exact confirmed minimal payload and returns an untrusted
  Draft. No raw file, raw row, path, original identifier/group, credential,
  unselected log, or transcript enters a payload or product history. Raw
  identifiers remain authorized only in user-selected local files, their
  immutable local snapshots, calculation input memory/stdin, the local group
  pseudonym map, and synthetic credential-free test CSVs; they are prohibited
  from outbound, IPC, logs, report, Run, screenshot, and evidence captures.
- Reports in 060_reports are immutable projections of referenced authority.
  Final means accepted Finding plus Decision Closure, never Action or Outcome.
