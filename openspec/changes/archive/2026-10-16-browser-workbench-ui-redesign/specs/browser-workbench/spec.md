# BUI approved behavior delta

## Shell and retained behavior (R01–04/08–11)
Single sidebar/topbar; same task conversation/results/evidence views, results overview/data/report, three inspector groups retaining five old detail pages. Professional home/prepare/process/analysis/report/feedback render actual retained pages, not progress indicators. View/mode/stage changes are read-only and preserve task draft/citations/reading position. Same-task compact assistant shares the composer. Local table scroll, mobile overlays with focus return, readable Chinese labels.

New-task drafts and file selections are project-local as well as task-local. A/B project round trips restore only the owning project's home/task draft; session reload never resurrects serialized file bytes. Unscoped legacy UI cache keys are not silently adopted as a current project's draft.

## Stable references (R05)
Reference only saved paragraph or current source-bound finding ID. Resolve before send on the owning task; reject stale report/source/revision or lost authority. No raw preview row indexing; no cross-task carry. Text one paragraph, at most 1500 characters; mouse/keyboard or paragraph fallback. No implicit request on selection.

## Report content (R06/07/12)
One current saved draft with locked facts/scope/limits and editable plain text interpretation marked provenance and not newly fact-verified. Manual save, selected verified finding inclusion, suggestion request/compare/apply/discard and history. No-op does not advance. Concurrent save rejects, retains local text next to current server version and requires re-edit/discard. Unknown retains command and queries receipt; never repeats. Every saved content change invalidates content confirmation only, preserving old analysis judgments. New confirmation requires exact current saved content/source/outcome and no unresolved suggestion, unknown/write restriction/local draft. Partial confirmation never completes a task. Download marks unconfirmed/confirmed version and is not a content mutation. Legacy appended expressions are historical only, not auto-promoted or auto-confirmed.

Settled waiting with applicable saved verified steps permits partial-content editing/confirmation, leaving the task waiting and incomplete. Running/checking/UNKNOWN steps, pending stop or preview, and unconfirmed physical effects remain fenced. Current and historical exports preserve the immutable numeric catalog, including derived/not-applicable values, scopes, units, formula inputs, limitations and proof identities independently of editable wording or manually included findings.

## Safety and verification
Retain loopback/same-origin/session/control and existing authorization. No real Provider/data/action in implementation verification. Existing calculation, method, collaboration, assets and formal review applicability must remain accessible and pass affected regression. User product acceptance remains pending until explicit trial verdict.
