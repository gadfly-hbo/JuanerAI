# DP-RUNTIME / DP-WRITE / DP-HOST 验收

- DP-RUNTIME-01：精确来源、teach、接收方的有效许可逐次检查；模型或发布无许可、撤销、过期、改变均拒绝。上传落盘确认不证明模型完成。
- DP-RUNTIME-02：复用 c11f8da composeAgent，首请求计入最多2次，备用与格式修复共享余量。真实 SDK 合成 codec 核对物理调用和原账本，不重置 UNKNOWN。新操作 ID/重开不得越过项目未知预留。
- DP-WRITE-01：宿主唯一项目成员检查；只允许采纳/有理由驳回、人工补充、已采纳项建任务、任务更新、人工反馈及明确重抽。拒绝跨项目 ID、未采纳建任务、未经批准接口。
- DP-WRITE-02：重复操作仅返回原确认回执；丢回执、未找到、多个匹配保持 UNKNOWN。查回不发第二个 POST；核对实际持久对象全部相关字段。
- DP-HOST-01：保存报告目录只提供实际宿主报告/Studio交付副本；HTML拒绝，无路径/任意文件输入。选择绑定精确字节，保留来源版本、资格/限制、返回原分析；另任务不得借用来源。
- DP-HOST-02：浏览器沿用既有会话/同源/控制权；GET历史不写插件数据，业务POST需控制权。目录和来源查看不会自动授权模型。关闭页面不取消抽取。
- DP-HOST-03：006r1完整看板、汇报模式、原生组件与视觉复用。合成验证包括保存报告→许可→异步抽取→采纳→任务→反馈→重开，以及 UNKNOWN 暂停写入但可读历史。真实浏览器限制继续明示，静态/HTTP不能替代人验。
- DP-RES-01（DP08/C01/C02，私有本地合成资源）：按runtime-design.md的先行细化，可信宿主提供独立清单摘要后才可消费包内固定Node/入口/依赖/通知；搬移不改变身份。缺件、换件、开发路径链接、越界清单和执行权限丢失在导入/启动前拒绝，无全局环境回退。实际本机合成闭环不替代正式安装、干净机、发行许可或浏览器验收。
