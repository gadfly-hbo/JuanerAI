# 单一 Provider 模型接入 · 增量 UI Contract v1

状态：拟议可点击界面，等待受影响用户 UI Gate；不是正式应用功能。

打开 index.html，先从顶部“模型未配置”或右侧“配置模型”进入。先填入演示 Key，再测试、保存并启用。更换、取消编辑、取消测试、删除确认、模式切换及重新打开面板都可点击。底部“演示状态”可预设下一次测试/存储结果，模拟任务运行、凭据失效和应用重开。先关闭配置面板再选择演示场景。

全部状态合成：CSP connect-src none，零模型/网络请求、零钥匙串访问、零浏览器持久化。输入仅在当前输入框短暂存在，关闭/保存时清空；内存只保存已配置布尔状态，不保存 Key。不要在原型输入真实 Key。刷新网页会重置；“模拟应用重开”演示正式应用的预期状态，不证明真实凭据持久化。

## 核对路径

1. 未配置 → 输入演示 Key → 测试成功但未保存 → 保存启用 → 完成；顶部与任务面板同步显示模型，任务仍未开始。
2. 关闭再打开：已保存 Key 不回填，只显示掩码；模拟重开不调用模型。
3. 更换：输入新演示 Key，测试失败/取消/未保存关闭，旧配置仍在。成功保存后才替换。
4. 选择 Key 无效/网络不可用/额度不足/超时，点击测试，看到对应原因及恢复动作；不自动重试。
5. 选择存储失败后保存/删除：显示未完成，旧配置保持；钥匙串不可用时不降级为明文。
6. 任务运行/等待回复时，配置仍可查看，测试/更换/删除暂不可操作；停止任务后再变更。
7. 删除需确认；取消不变，成功回到未配置，Case/对话/草案/报告保留。
8. 已配置后“查看任务授权”说明沿用原 Change002 授权流程；本附件不重复实现原业务流程。
9. 在快速/专业模式，顶部入口一致。1440×900、1280×720 下均可操作；Tab、Shift-Tab、Escape 与焦点返回可验证。

base.css 与品牌图逐字复制冻结 Change002 原稿；新增 panel.css 使用相同颜色、字体和表单层级。工作台仅为背景定位，完整 Case 流程由原 UI Contract 约束。范围与验收见 ../provider-settings-product-input-v1.md。
