D3：保留插件项目级 teach 对后续抽取的作用，但仅属于该插件项目的偏好/纠错上下文，不自动发布 Hypothesis/Strategy/Pack，不改旧报告，不跨项目传播；不是已完成 N07/N08 学习治理。用户可选择先禁用该反馈用途，但需核对原插件是否支持且避免在宿主重写业务。

## 任务路径与关键语义

1. 从同任务已保存的报告或 Report Studio 稳定交付副本选择精确版本。来源至少保留宿主项目、任务、分析/报告版本、文件摘要和原交付身份。原始明细/会话/整库不随报告发送。首轮逐个报告授权，不隐式整批导入。
2. 显示将发送的具体文件、用途、主备模型接收方及限制；命中仍有效许可时自动推进。取消选择不创建上传或抽取。格式匹配：Report Studio 已有 PPTX/PDF 可候选接入；其 HTML 不在 Prompt 支持清单，不静默转格式。JuanerAI Markdown 须从当前版本的正式输出取得。
3. 宿主在独立数据根创建/读回绑定的插件项目，上传这版报告后读取 reports[].status。pending/extracting/done/failed 是插件抽取状态；done 不表示人已采纳或反馈有效。
4. 人在插件页面检查引用与证据等级，采纳或驳回（仅驳回理由必填），再为采纳项记录任务。模型置信度不覆盖人的决定。字段/枚举不从 Prompt 外补猜，固定材料到达后核对；不足回到上游，不在宿主复制业务。
5. 人填写反馈后读回原任务的已保存记录；失败保留输入，未知先读回，不能因 HTTP 超时重复 POST。读取到反馈不宣称现实任务完成、观察合格或因果成立。
6. 原分析可以查看这一绑定的看板/报告/任务/反馈及来源。候选明确一个宿主任务对应一个插件项目；同任务的不同报告/新版在同项目生成独立报告身份与关联，不覆盖旧版，项目级 teach 可用于同任务后续抽取。另一宿主任务必须进入另一插件项目，不共享 teach；不靠标题匹配。数据库字段仍由工程确定。此映射为002新增待审产品选择。
7. 刷新/关闭标签仅关闭视图，不声称停止抽取；停止受理、在途、物理结束、UNKNOWN 分开。Prompt 没有取消/账本读回合同，未证实前不承诺安全取消、自动重试或强杀后恢复。活动/未知不得热换；首次新数据根不能指向独立版旧库（M5 旧库迁移可能删文件重建）。
