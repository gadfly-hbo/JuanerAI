## 审核路径

1. 默认进入新版工作台成果/报告编审→“送入决策看板”→选报告→许可说明→“允许合成范围并演示”→明确抽取中→审核专用“模拟抽取完成”。
2. 点行动标题展开证据；采纳第一项→添加任务→填写负责人/截止日→保存；切任务状态→填写反馈/评分→保存；返回原分析看人工反馈计数→继续查看同一看板。
3. 驳回另一项，空理由应拒绝；填写理由后读回。使用汇报模式查看同一建议及拍板；过滤和人工补充沿原插件组件。
4. 选“来源已有新版”，宿主选 v2→确认材料/用途→演示抽取完成，v1/v2 并存且原已决记录不被移走。切“会员复购：先把需求想清楚”，不带入当前报告/teach。
5. 选“写入结果未知”，打开原关联→查看已有证据、核对仍未知，写入和重抽不能推进；选“已找到原回执”只恢复读回，不再次提交。
6. 选“反馈保存失败”，采纳/建任务/填写反馈后保存失败，输入保留；审核专用模拟通道恢复后再保存。检查模型配置缺口、许可缺口、启动失败、来源不可用和坏包。

审核场景下拉、合成就绪/完成/恢复按钮只用于原型；正式产品不含这些控制、不定时造成功、不显示模型思考链。所有原型操作仅内存，刷新重置。

## 可访问性与验证限制

原生 button/select/dialog/label 优先，新增弹窗支持 Esc、模态焦点及返回触发控件，状态文字和持久反馈保留。复用原插件组件的访问性仍须实际检查。目标 1440×900、1366×768，390px仅布局健壮性，不扩大移动交付。

本轮构建与服务端静态渲染检查可执行；实际浏览器 file:// 被安全策略拒绝，未绕过。**视觉截图、尺寸与真实点击/键盘检查 NOT_RUN**，不能宣称布局一致或 UI PASS。用户可自行打开离线文件审核；取得允许的测试路线后补实测。该限制不由静态审查抵消。

## 003 原型纠正（产品语义不变）

独立002指出的R1–R3已作为本次合并纠正：每行查看/重抽显式传入报告身份；p2显示自身无报告来源并返回p2任务；已有关联同版送入只打开原关联，只有独立重抽进入替换确认。增加“渠道补充报告 v1”合成选项和明确 task/delivery/内容标识卡。

追加审核：送入v2后点v1行重抽，确认目标必须仍为v1；查看v1再点v2行重抽必须为v2。切p2→来源显示p2无报告→返回p2原分析。再次选择同版v1送入只显示已有关联、不进入抽取中。增加同任务补充报告后原报告来源与已决项仍保留。实际浏览器验证仍NOT_RUN，独立复审仅按静态可推导行为。


004 对应纠正：请求受理时保存独立的项目/报告目标，抽取完成只读该目标；查看其他来源不改变在途目标。许可按具体报告身份集合保留，同版有效许可复用，新文件/新版必须展示其材料范围。追加审核：v2受理后查看v1，再模拟完成仍新增v2；已允许v1后选择渠道报告必须进入该文件的许可说明。标签按目标报告显示抽取状态。

## 006：看板视觉与汇报模式纠偏

用户指出汇报入口不明确、看板视觉色彩不符；其截图是005抽取中场景。006保持抽取中不能冒称已有新结果，但显示禁用理由并提供审核专用“模拟完成并进入汇报”。新增独立审核入口：

- [直接看板示例](clickable/index-006-board.html)：加载已完成的合成样例，进入按钮可用。
- [直接汇报示例](clickable/index-006-presentation.html)：直接进入合成汇报总览；选择议程进入逐项证据/采纳/驳回，保留原有键盘操作。
- [完整宿主到看板流程](clickable/index-006.html)：保留选材、许可、在途与故障审核路线。

这些页面只选择初始合成演示状态，不代表运行过抽取、不跨文件保存、不引入真实权限。直接示例不清空原流程页的内存操作。正常产品“进入汇报模式”仍按任务、关联与请求状态检查；禁用时显示文字原因。

汇报新增可见“退出汇报 · Esc”入口，退出回同一看板，保留已作人工决定。汇报期间后台页面inert/aria-hidden，避免键盘落入背景；原驳回原生dialog继续管理焦点。浏览器全屏失败时沿用原CSS全屏回退，不强迫用户启用API。实际浏览器/键盘验证仍NOT_RUN。

视觉统一：canvas #f6f7f4，surface #fcfcfa，sidebar #f0f2ed，主动作 #27664f，正文 #36443f，辅助 #59665e。看板侧栏连续浅灰绿、概览和报告区域用细分隔，行动项保留边界卡片；汇报沿用同一色板和放大内容，不保留橘色主按钮。警告/失败保留具名状态和对应语义色。

006r1对应纠正：抽取进度和“模拟完成并进入汇报”只呈现在请求所属项目；完成跳转固定回受理项目。任何汇报view的报告/议程也按当前项目隔离，会员任务不得含销售议程。直接示例初始HTML即启用同一主题，避免等待effect前的旧样式闪现。
