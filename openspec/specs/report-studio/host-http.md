# RS-HOST-HTTP-01：宿主既有会话中的关联操作

沿用宿主loopback/Host/Origin/session保护；状态和目录读取不启动模型，任何打开/创建/继续/交付动作须当前宿主控制权。没有内置组合时明确not_bundled，不创建项目或回退独立版。

每个关联业务URL含明确宿主project_id；请求在进入及异步结果返回时都核对项目对象仍相同，项目切换后的旧请求不能将回执显示成当前项目成功。材料目录和绑定按task/revision精确读取；打开/继续签发精确Studio项目bootstrap URL；交付与回执按association/export，下载只按宿主已保存delivery，不接受任意文件路径。

结果只包含业务元数据和一次性浏览器URL，不传owner token、程序路径、原分析库接口或模型凭据。稳定副本下载以attachment及禁脚本CSP呈现，保持三格式和警告。HTTP成功不替代浏览器实际接收/用户落盘，也不代表模型制作通过。
