# Packages

- product-core/: infrastructure-independent business concepts and rules.
- application/: use cases and workflow coordination.
- ports/: business capability interfaces.
- contracts/: executable shared contracts after approval.
- domain-pack-sdk/: Domain Pack authoring and runtime contract.
- model-pack-sdk/: Model Pack authoring and runtime contract.

These are module boundaries, not approved package-manager choices or separate repositories.
