# Adapters

- agent-pi/: Pi implementation of Agent Runtime behavior.
- analytics-duckdb/: local analytical data behavior.
- state-sqlite/: personal operational-state behavior.
- semantic-semantica/: candidate Ontology, Knowledge, or Memory integrations.
- storage-local/: local artifact storage.
- llm/: model-provider integrations.

No Adapter API, dependency, or version is approved during cold start.
